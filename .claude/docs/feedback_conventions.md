# Conventions de fichiers — feedback

Ne jamais inventer des noms de fichiers de convention inexistants (ex: `AGENT.md`).

Conventions reconnues :
- `CLAUDE.md` — chargé automatiquement par Claude Code dans le contexte des agents
- `.claude/docs/` — docs pour les agents dans ce projet
- `README.md` — documentation standard npm/GitHub pour les humains
